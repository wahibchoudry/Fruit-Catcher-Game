# 🍓 Fruit Catcher Game

**Fruit Catcher** is a simple and fun browser-based game built with **HTML, CSS, and JavaScript**. The goal is to catch as many falling fruits as you can while avoiding misses. Miss 5 fruits and the game ends! 🎮

## ✨ Features

* 🎨 **Animated Menu Background** – Fruits fall in the background while you navigate the menu.
* 📖 **Instruction Screen** – Easy-to-understand guide on how to play.
* 🎮 **Gameplay** – Control a basket using **Arrow Keys** to catch fruits.
* ⚡ **Smooth Controls** – Responsive basket movement for a better experience.
* 🏆 **Scoring System** – Gain points by catching fruits, game over after 5 misses.
* 🖥 **Responsive Design** – Works on desktop browsers without any setup.

## 🕹 How to Play

1. Open the game in your browser.
2. From the main menu, click **Play Game** to start.
3. Use **⬅ Left Arrow** and **➡ Right Arrow** to move the basket.
4. Catch fruits to earn points.
5. If you miss **5 fruits**, the game ends.

## 📂 Technologies Used

* **HTML5** – Structure and canvas for the game.
* **CSS3** – Styling and animated backgrounds.
* **JavaScript (Vanilla JS)** – Game logic, controls, and animations.

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/fruit-catcher.git
   ```
2. Open `index.html` in your browser.
3. Play and enjoy! 🎉
